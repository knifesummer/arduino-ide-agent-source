# 思考展示与提示词定制

## 展开思考

每条含思考数据的回复都有独立折叠区，默认收起。点击“思考过程”或“推理摘要”查看内容，可以复制文本。思考与回答分别保存，历史对话重新打开后仍可展开。没有相关数据的回复只显示正文，不生成假的思考记录。

- OpenAI Chat Completions 兼容接口：接收公开的 `reasoning_content` 或 `reasoning` 文本。
- OpenAI Responses：请求并接收推理摘要；兼容第三方接口公开返回的 `reasoning_text`。增量、完成事件和最终快照不会重复展示。
- Anthropic Messages：接收 thinking 内容块及增量。签名、加密内容和 redacted thinking 不展示；必要的协议字段仍原样回传工具轮次。

OpenAI 的摘要不等于完整内部思维链。Anthropic 新模型的 thinking 文本同样可能是摘要；不同提供商是否返回内容取决于模型和接口。设置里的展示选项与模型的推理等级共同控制请求，开启可能增加耗时和用量，不支持可选参数的中转会自动降级。

## 修改内置提示词

右侧面板 → 设置 → 内置提示词 → 展开编辑器。

1. 修改整个默认提示词，或清空后填写自己的规则。
2. 根据需要选择是否自动附加当前工程、板卡及近期操作上下文。
3. 点击“保存提示词”，下一次请求使用新规则，当前请求不受影响。
4. “恢复默认”把默认规则填回编辑器，需要保存后生效；“撤销编辑”恢复本次编辑前的已保存内容。

自定义规则完整替换默认规则。关闭自动上下文后，不额外附加默认规则、版本说明或工程快照；可以保存空提示词。自动上下文关闭只影响 IDE 主动附加的信息，用户仍可要求模型通过可用工具读取工程。

提示词最多 120000 个字符，超出会明确拒绝，避免静默截断。配置保存在本机，与对话历史一起保留；发布 ZIP 不带个人提示词或历史。编辑提示词只修改对应设置，不会把尚未保存的接口地址或 API Key 一起提交。提示词能够改变模型行为，实际工具及硬件确认仍由程序的权限设置决定。

## 验证

自动回归覆盖三种协议的流式与非流式思考解析、摘要去重、签名隔离、历史恢复、自定义规则完整替换和配置迁移。界面验收覆盖思考展开/收起、中文及换行输入、后台更新、提示词保存与默认恢复、窄屏与深色主题。OpenCode Go 的真实流式请求已返回思考通道，验证时不操作真实工程或硬件。
